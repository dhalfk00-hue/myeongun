# 손명리 - 사주 풀이·결혼 궁합

사주 풀이(좋은 해엔 조심할 점, 약한 해엔 보완법)와 결혼 궁합을 보는 모바일 웹앱이에요. 규칙 기반 해석이라 외부 AI API를 쓰지 않아요.

- 손금 기능은 지금 꺼져 있어요. 환경 변수 `PALM_ENABLED=1`로 켤 수 있어요(켜도 손 사진은 휴대폰 안에서만 분석).

- 입력한 생년월일과 감정서 파일은 서버 임시 폴더에 24시간만 두고 자동으로 지워요.
- 지금은 테스트 단계라 결제 없이 감정서를 열 수 있어요.

실행: `docker build -t sonmyeongri . && docker run -p 10000:10000 sonmyeongri`

전통 명리 해석에 기반한 재미·참고용 콘텐츠예요.
