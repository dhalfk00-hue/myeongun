# 명운 · 사주 궁합 손금

만세력 기반 사주 신년운세, 결혼 궁합, 손금 재물운을 보는 모바일 웹앱이에요. 규칙 기반 해석이라 외부 AI API를 쓰지 않아요.

- 손 사진은 휴대폰 안(브라우저)에서만 분석하고, 서버에는 선 좌표·특징만 보내요.
- 입력한 생년월일과 감정서 파일은 서버 임시 폴더에 24시간만 두고 자동으로 지워요.
- 지금은 테스트 단계라 결제 없이 감정서를 열 수 있어요.

실행: `docker build -t myeongun . && docker run -p 10000:10000 myeongun`

전통 명리·수상학 해석에 기반한 재미·참고용 콘텐츠예요.
